# 鬼灭之刃角色性格测试

纯静态网页，可直接上传到 GitHub Pages，不需要安装软件、配置后台或 API 密钥。

## 上传发布

1. 下载并解压压缩包。
2. 建议新建一个独立的 GitHub 仓库，例如 `demon-slayer-quiz`，避免覆盖你之前的排球少年网页。
3. 把 `index.html`、`cover.png` 和 `README.md` 上传到新仓库根目录并提交。
4. 在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
5. 等待 GitHub Pages 显示网页地址。

## 网页内容

- 15 道日常情境题，约 2 分钟
- 8 位角色匹配：炭治郎、祢豆子、善逸、伊之助、义勇、忍、杏寿郎、香奈乎
- 行动力、共情力、冷静度、意志力四项分析
- 多角度性格解读、行动建议、结果分享链接
- 原创大正和风封面，水纹、火焰与藤花氛围
- 角色结果展示原作/动画台词节选
- 无外部脚本依赖，适配手机浏览器

这是非官方粉丝向娱乐测试。封面为原创风格插画；角色台词为原作/动画节选。GitHub Pages 只托管静态页面，不含收款或付款后自动发货功能。
